# Module 2.1 — Optimized Script

## Frame The Leadership Problem And Define "Group DNA"

| | |
|---|---|
| **Duration** | 35–45 min |
| **Objective** | Align on the leadership problem · Define first-pass Group DNA themes · Identify priority use cases |
| **Inputs** | Company context · Brand list · Examples of leadership behaviors |
| **Deliverables** | 1-page problem statement · Competency matrix CSV (4 themes × 3 levels) · 10-slide CEO pack |
| **Grounding** | Stay anchored in The Company Group context and the four themes: **Vision · Entrepreneurship · Passion · Trust** |

---

## Moderator Opening  _(read aloud)_

> Today we are framing the leadership problem and defining The Company Group's leadership DNA. We are not finishing the full model today — we are aligning on the problem statement, extracting the Group DNA themes, and identifying first use cases.

> Core tension: preserve brand autonomy **while** building Group-wide strength in mobility, pipeline, and leadership consistency.

> We capture outputs in **three formats** as we go:
> - **Final Plan** — working design content
> - **Executive Update** — direction and decisions for leadership
> - **Internal Comms** — stakeholder summary after the session

---

## Facilitation Flow

### Step 1 · Define The Leadership Problem `8–10 min`

**Prompt:** _What leadership problem are we solving at Group level?_

| Follow-up | |
|---|---|
| Where must brand autonomy stay protected? | |
| Where does the Group need more consistency? | |
| If nothing changes, what business/talent risks remain? | |
| One-sentence problem statement? | |

**Capture → Executive Update**
> Business problem · autonomy vs. consistency tension · why now · where alignment is needed

**Expected output**
- Draft problem statement
- Articulation of the autonomy / consistency tension
- Rationale for a Group model

---

### Step 2 · Surface The CEO Lens `7–8 min`

**Prompt:** _What would we need to understand from the CEO about business direction and leadership culture?_

| Follow-up | |
|---|---|
| What does Group success look like in 3–5 years? | |
| What leadership culture enables that ambition? | |
| What should be common across all brands? | |
| What must remain distinct at brand level? | |

**Capture → Final Plan + Executive Update**
> Final Plan: CEO business direction · leadership implications · shared vs. protected expectations
> Executive Update: refresh with any language that sharpens the business case or changes design criteria

**Expected output**
- Leadership design criteria from CEO lens
- Shared vs. brand-specific expectations

---

### Step 3 · Surface The CHRO Lens `7–8 min`

**Prompt:** _From the CHRO perspective, what is Group HR enabling through this model?_

| Follow-up | |
|---|---|
| How does the model support Group HR's mission? | |
| Observable meaning of Vision / Entrepreneurship / Passion / Trust? | |
| What should vary by leadership level? | |

**Capture → Final Plan**
> HR intent · first interpretation of four themes · level-differentiation implications

**Expected output**
- HR design intent
- Early behavioral interpretation of all four themes
- First view on level differentiation

---

### Step 4 · Build The First-Pass Competency Model `10–12 min`

**Prompt:** _Let's build the first-pass model across Vision, Entrepreneurship, Passion, and Trust._

| Follow-up | |
|---|---|
| 2–3 behaviors per theme? | |
| How do behaviors differ across three leadership levels? | |
| Which behaviors are essential, observable, assessable? | |
| What makes this distinctly The Company Group vs. generic? | |

**Capture → Final Plan** _(full replacement, not append)_
> Four themes · first-pass behaviors · level differentiation · open design questions

**Expected output**
- First-pass competency model structure
- Theme definitions
- Behavior examples by level
- Open issues for refinement

---

### Step 5 · Map Use Cases `5–7 min`

**Prompt:** _Where will this model create value first?_

| Follow-up | |
|---|---|
| How does it inform recruitment? | |
| How does it support appraisal / performance? | |
| How does it guide development and succession? | |
| How does it support cross-brand/market mobility? | |

**Capture → Final Plan + Internal Comms**
> Final Plan: priority use cases · requirements per use case · sequencing assumptions
> Internal Comms: what was aligned · expected usage · what teams should expect next

**Expected output**
- Prioritized use case list
- Phase-one application view
- Stakeholder-ready summary of intended uses

---

### Step 6 · Close And Confirm Outputs `3–5 min`

**Closing:** _Let's confirm what we take forward: problem statement · first-pass Group DNA · behavior model · priority use cases._
_Confirm what needs executive input, what needs HR follow-up, and what is ready for broader stakeholders._

**Capture → Executive Update + Internal Comms**
> Executive Update: final position · what was agreed · what needs endorsement · next deliverables
> Internal Comms: workshop summary · what was aligned · what happens next

**Expected output**
- Final executive summary for leadership
- Internal stakeholder summary
- Clear next actions

## Recommended Artifact Shape

### Final Plan
- Problem statement
- Design principles
- Shared vs. brand-specific leadership expectations
- Four Group DNA themes with definitions
- Behavior examples by level
- Priority use cases
- Open issues and next steps

### Executive Update
- Why this matters now
- Core leadership tension
- Direction emerging from the session
- Decisions made
- Decisions still required
- Next deliverables

### Internal Comms
- What the workshop covered
- What was aligned
- What the model is intended to support
- What happens next
- Who is involved next
